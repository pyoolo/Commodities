# Notebooks

Exploratory analysis, charts and quick studies.

## Convention
Name notebooks `YYYY-MM-DD_topic.ipynb` so the history stays readable.

Each notebook should state at the top:
1. The question being asked
2. The data used and its source
3. The conclusion — even if it is "no signal here"

Negative results are kept. They are the cheapest way to avoid repeating work.

## Housekeeping
- Clear outputs before committing, or use `nbstripout`, to keep diffs usable.
- Anything reused more than twice gets promoted to a module in the relevant folder.
